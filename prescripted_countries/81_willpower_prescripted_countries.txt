#   warmongers：排外 + 狂热军国 + 独裁 → 民族主义热忱、卓越海军部、
#               战士文化、公民义务（后两者只要求军国思想）
#   open_stars：平等 + 狂热亲外 + 民主 → 议会制、精英政治、
#               理想主义基金会、自由灯塔（均不限权力制度或要求民主/非威权）
# 四个理念也与本模组 GOVERNMENT_CIVIC_POINTS_BASE = 4 的点数规模对齐。
